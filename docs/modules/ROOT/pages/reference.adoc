= Reference

These reports are generated during the Maven build and site lifecycle.
When `target/site` is published into the documentation site as `mvn-site`, they are available from the documentation output.

== Generated Reports

|===
|Report
|Description

|link:../mvn-site/apidocs/com/irurueta/hermes/package-summary.html[Javadoc]
|API reference generated by the Maven Javadoc plugin as part of the Maven site.

|link:../mvn-site/jacoco/index.html[JaCoCo]
|Code coverage report generated during Maven execution.

|link:../mvn-site/surefire-report.html[Surefire]
|Unit test execution report generated by the Maven Surefire reporting tools.

|https://sonarcloud.io/project/overview?id=albertoirurueta_hermes[SonarCloud]
|Project quality dashboard with issue analysis, code quality information, and coverage metrics.
