# Uploads, file responses, streaming, WebSockets

Read this when the task adds file uploads or downloads, a `StreamingResponse`, a JSON Lines or SSE stream, or a
WebSocket endpoint.

## Uploads

- `UploadFile` for anything non-trivial (spooled to disk past 1 MiB; `filename`, `content_type`, `size`);
  `Annotated[bytes, File()]` only for tiny payloads. Forms and files need `python-multipart` (in
  `fastapi[standard]`); `Form()`/`File()` switch the body to form/multipart — a JSON model can't share the request
  (send JSON as a `Json[Model]` form field, or upload in a second request).
- **Treat `filename` and `content_type` as untrusted**: allow-list the type *and* check magic bytes, generate the
  stored name, copy in chunks with a byte cap, and clean up on overflow:

```python
@router.post("/covers", status_code=status.HTTP_201_CREATED)
async def upload_cover(cover: UploadFile) -> dict[str, str]:
    """Store a PNG cover under a generated name, in chunks, with a size cap."""
    head = await cover.read(len(PNG_MAGIC))
    if cover.content_type != "image/png" or head != PNG_MAGIC:
        raise HTTPException(status.HTTP_415_UNSUPPORTED_MEDIA_TYPE, "PNG only")
    await cover.seek(0)
    target = UPLOAD_DIR / f"{uuid.uuid4().hex}.png"
    written = 0
    async with await anyio.open_file(target, "wb") as out:
        while chunk := await cover.read(CHUNK):
            written += len(chunk)
            if written > MAX_BYTES:
                await out.aclose()
                target.unlink(missing_ok=True)
                raise HTTPException(status.HTTP_413_CONTENT_TOO_LARGE, "Too large")
            await out.write(chunk)
    return {"name": target.name}
```

- `async def` uses the awaitable `UploadFile` methods; a `def` endpoint uses `cover.file` (`shutil.copyfileobj`),
  which is also the shape for blocking SDKs (`boto3.upload_fileobj`). Never `await cover.read()` without a size.
- FastAPI has no global body limit: the proxy limit comes first; `RequestBodyLimitMiddleware` (Starlette 1.7+) or a
  pure ASGI middleware for the app; a dependency is **not** an early check (the form is parsed before it runs).
- Storage behind a `Protocol` (`CoverStorage.save(...)`) injected via a dependency so tests override it; container
  disks are ephemeral — multi-instance deployments use object storage (the project's existing one).
- Never `Form()` on `GET`; browser file forms need `method="post"` + `enctype="multipart/form-data"`; clients must
  not set `Content-Type` by hand for multipart (lost boundary → 400).

## File responses

- `FileResponse` for files on disk (ETag, Last-Modified, Range). A client-supplied name is a path-traversal vector:
  resolve it and check `target.is_relative_to(BASE)` and `target.is_file()` → otherwise 404. For object storage,
  prefer a short-lived signed URL.
- `RedirectResponse` defaults to 307; use 303 after a successful form POST. Never redirect to an unvalidated URL
  from the query (open redirect).
- Returned `Response` objects bypass validation and OpenAPI: declare `response_class=` and
  `responses={200: {"content": {"image/png": {}}}}` so the docs are right.

## Streaming

| Need | Shape |
|---|---|
| Generated bytes/text (CSV export) | `StreamingResponse(gen(), media_type="text/csv", headers={"Content-Disposition": ...})`, or a `StreamingResponse` subclass with `media_type` + `yield` in the path operation |
| Items to a program | JSON Lines: an `async def`/`def` path operation that **yields** models, annotated `-> AsyncIterable[Token]` / `-> Iterable[Token]` (`application/jsonl`, items validated) |
| Events to a browser | SSE: `response_class=EventSourceResponse` + `yield ServerSentEvent(data=..., event=...)` (`from fastapi.sse import ...`, 0.135+; replaces `sse-starlette`) |

- Status and headers leave with the first chunk: **do every check (auth, 404) in dependencies**, which run before
  streaming. An `HTTPException` inside the generator yields a 200 followed by a broken stream; emit an application
  error event instead.
- Read files in fixed chunks with the `with` *inside* the generator; `async` generators must not block (use
  `anyio.open_file`), `def` generators run in the threadpool.
- `ServerSentEvent(data=...)` always JSON-encodes (strings get quotes); `raw_data=` for literal text like `[DONE]`.
  `Last-Event-ID` → `Annotated[str | None, Header()] = None` (an `int` type with non-numeric ids 422s every
  reconnect).
- Long streams must not hold a request-scoped DB session: open short-lived sessions per query inside the generator
  (or `Depends(..., scope="function")` for dependencies the generator doesn't use). Cleanup in `finally`; re-raise
  `CancelledError`. Bounded queues per subscriber; in-process fan-out reaches only one worker.

## WebSockets

```python
@router.websocket("/ws/chat")
async def chat(websocket: WebSocket, ticket: TicketDep) -> None:
    """Echo validated messages."""
    await websocket.accept()
    async for raw in websocket.iter_text():
        try:
            message = ChatMessage.model_validate_json(raw)
        except ValidationError:
            await websocket.send_json({"kind": "error", "detail": "invalid message"})
            continue
        await websocket.send_json({"kind": "echo", "text": message.text})
```

- FastAPI validates only the handshake (`Path`/`Query`/`Header`/`Cookie`/`Depends`); **validate every message**
  with a Pydantic model (discriminated unions for several kinds) and answer bad ones in-band.
- `async for ... in websocket.iter_text()` (ends cleanly on disconnect) instead of `while True: receive_text()`;
  cleanup and "leave" broadcasts in `finally`.
- Reject with `WebSocketException(code=status.WS_1008_POLICY_VIOLATION, reason=...)`, never `HTTPException`; before
  `accept()` a real client sees only an HTTP 403. Reasons short, no secrets.
- **Auth**: `OAuth2PasswordBearer`/`HTTPBearer` can't be WebSocket dependencies. Browsers can't send headers —
  use a seconds-lived ticket (a JWT with its own `aud`, minted by an authenticated HTTP endpoint) in the query, or a
  cookie **plus an `Origin` allow-list check** (CORS doesn't apply to WebSockets). Never long-lived access tokens in
  URLs.
- One DB session per message, not per connection; bounded sends (`asyncio.wait_for(ws.send_text(...), 2.0)`) when
  broadcasting; per-process connection managers don't span workers (Redis pub/sub when the project has it).
- Tests: `with TestClient(app) as client:` + `client.websocket_connect(url)`; rejections raise
  `WebSocketDisconnect` with `.code` (verified: 1008 under `TestClient`); `receive_*` blocks forever if nothing is
  sent — keep tests deterministic.
