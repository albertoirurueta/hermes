# Sample feature and the four test levels

A deliberately tiny "greeting" feature the scaffold ships so every build gate has something real to run on day one:
a `@ConfigMapping`, an `@ApplicationScoped` service, a `@Path` resource, and **one test per level** from
`iru-quarkus-code-one-task/reference/testing.md`. It follows the catalog's Java/Kotlin rules (`java.md` / `kotlin.md`
there) so Checkstyle/detekt/ktlint and the Javadoc/KDoc audits start at zero findings, and its plain + component
tests alone reach 100% line coverage, so the 80% check passes in `ci-tests: unit` as well as `full`.

Substitute `<base-package>` and `<artifact-id>`; paths below are for a **single-module** build (hexagonal builds use
`hexagonal.md`'s module-by-module version instead). Every file here was compiled and run, unchanged apart from the
placeholders, on Quarkus 3.40.1: Java on Maven and on Gradle, Kotlin on Gradle and on Maven.

| Level | Class | Starts | Counts toward the 80% check in `ci-tests: unit` |
|---|---|---|---|
| 1 plain unit | `GreetingServiceTest` | nothing | yes |
| 2 component | `GreetingServiceComponentTest`, `GreetingResourceComponentTest` | CDI beans under test only | yes (via `quarkus-jacoco`, see `maven.md`/`gradle.md`) |
| 3 full app | `GreetingResourceTest` (`@QuarkusTest`) | the app on port 8081 + Dev Services containers when a Dev-Services-capable extension has no URL | only in `full` |
| 4 packaged | `GreetingResourceIT` (`@QuarkusIntegrationTest`) | the packaged jar as a separate process (+ Dev Services) | never (separate JVM) |

Placement of the level-4 class: **Maven** — `src/test/<lang>/…/GreetingResourceIT` (Failsafe picks up `*IT`), and in
Java it may simply `extends GreetingResourceTest`. **Gradle** — `src/integrationTest/<lang>/…`, the source set the
Quarkus Gradle plugin creates for `quarkusIntTest`; it can't see `src/test` classes, so it is a standalone class.

import io.smallrye.config.WithDefault;

@ConfigMapping(prefix = "greeting")

`…/greeting/GreetingService.java`

```java
package <base-package>.greeting;

import jakarta.enterprise.context.ApplicationScoped;

/**
 * Builds greeting messages. Stateless and thread-safe; never blocks.
 */
@ApplicationScoped
public class GreetingService {

    /**
     * Configuration providing the default name.
     */
    private final GreetingConfig config;

    /**
     * Creates the service.
     *
     * @param config configuration providing the default name.
     */
    public GreetingService(final GreetingConfig config) {
        this.config = config;
    }

    /**
     * Greets the given name, or the configured default name when none is given.
     *
     * @param name name to greet; {@code null} or blank uses the configured default.
     * @return the greeting message.
     */
    public String greet(final String name) {
        final var target = name == null || name.isBlank() ? config.name() : name;
        return "Hello " + target;
    }
}
```

`…/greeting/GreetingResource.java`

```java
package <base-package>.greeting;

import jakarta.ws.rs.GET;
import jakarta.ws.rs.Path;
import jakarta.ws.rs.Produces;
import jakarta.ws.rs.QueryParam;
import jakarta.ws.rs.core.MediaType;

/**
 * REST entry point of the greeting feature.
 */
@Path("/hello")
public class GreetingResource {

    /**
     * Service building the greeting.
     */
    private final GreetingService service;

    /**
     * Creates the resource.
     *
     * @param service service building the greeting.
     */
    public GreetingResource(final GreetingService service) {
        this.service = service;
    }

    /**
     * Returns a greeting for the given name.
     *
     * @param name optional name to greet.
     * @return the greeting message as plain text.
     */
    @GET
    @Produces(MediaType.TEXT_PLAIN)
    public String hello(@QueryParam("name") final String name) {
        return service.greet(name);
    }
}
```

`src/test/java/<base-package-path>/greeting/GreetingServiceTest.java`

```java
package <base-package>.greeting;

import static org.junit.jupiter.api.Assertions.assertEquals;
import static org.mockito.Mockito.mock;
import static org.mockito.Mockito.when;

import org.junit.jupiter.api.Test;

/**
 * Level-1 (plain unit) tests for {@link GreetingService}: no Quarkus, no container.
 */
class GreetingServiceTest {

    /**
     * Default name returned by the mocked configuration.
     */
    private static final String DEFAULT_NAME = "World";

    /**
     * Verifies that an explicit name is greeted as given.
     */
    @Test
    void greet_whenNameGiven_greetsThatName() {
        final var config = mock(GreetingConfig.class);
        final var service = new GreetingService(config);

        assertEquals("Hello Ann", service.greet("Ann"));
    }

    /**
     * Verifies that a missing name falls back to the configured default.
     */
    @Test
    void greet_whenNameMissing_greetsConfiguredDefault() {
        final var config = mock(GreetingConfig.class);
        when(config.name()).thenReturn(DEFAULT_NAME);
        final var service = new GreetingService(config);

        assertEquals("Hello World", service.greet(null));
    }

    /**
     * Verifies that a blank name falls back to the configured default.
     */
    @Test
    void greet_whenNameBlank_greetsConfiguredDefault() {
        final var config = mock(GreetingConfig.class);
        when(config.name()).thenReturn(DEFAULT_NAME);
        final var service = new GreetingService(config);

        assertEquals("Hello World", service.greet(" "));
    }
}
```

import jakarta.enterprise.context.ApplicationScoped

/**
 * Builds greeting messages. Stateless and thread-safe; never blocks.

 * @property config configuration providing the default name.

## `src/main/resources/application.properties`

Built from the manifest — include only the blocks for what was chosen. Keep the production-safe value unprefixed and
override per profile; never commit a credential, not even under `%dev` (`iru-quarkus-code-one-task/reference/configuration.md`).

```properties
quarkus.application.name=<artifact-id>

# Sample feature (replace with the service's real configuration)
greeting.name=World

# --- persistence: only when persistence != none -----------------------------------------------------------------
# <engine> via Hibernate ORM with Panache (or Hibernate Reactive), schema owned by <Flyway|Liquibase>.
# Dev and test get a Dev Services container automatically (no URL configured). Production connection settings come
# only from the environment: QUARKUS_DATASOURCE_JDBC_URL (or _REACTIVE_URL), QUARKUS_DATASOURCE_USERNAME,
# QUARKUS_DATASOURCE_PASSWORD. Don't add a %prod URL here: @QuarkusIntegrationTest runs the prod profile and would
# then skip Dev Services.
quarkus.datasource.db-kind=<postgresql|mysql|mariadb|mssql|oracle|db2>
quarkus.hibernate-orm.schema-management.strategy=<none (Flyway/Liquibase owns DDL; validate once entities exist)>
quarkus.flyway.migrate-at-start=true                # or quarkus.liquibase.migrate-at-start=true
# migrations: none → instead
# %dev.quarkus.hibernate-orm.schema-management.strategy=drop-and-create
# %test.quarkus.hibernate-orm.schema-management.strategy=drop-and-create

# --- observability: only for the extensions chosen ----------------------------------------------------------------
# quarkus-logging-json: JSON in deployed environments, readable console locally
%dev.quarkus.log.console.json.enabled=false
%test.quarkus.log.console.json.enabled=false
# quarkus-opentelemetry: exporter endpoint from the environment (QUARKUS_OTEL_EXPORTER_OTLP_ENDPOINT)
%dev.quarkus.otel.sdk.disabled=true
%test.quarkus.otel.sdk.disabled=true

# --- security: only when security != none -------------------------------------------------------------------------
# quarkus-oidc: dev/test use the Keycloak Dev Service; production issuer from QUARKUS_OIDC_AUTH_SERVER_URL.

# --- coverage (always) --------------------------------------------------------------------------------------------
# Plain, component and @QuarkusTest data are merged by the build (see pom.xml / build.gradle.kts); quarkus-jacoco's
# own second report would only wait 10 s for a file the build already reads.
%test.quarkus.jacoco.report=false
```

With persistence + Flyway, also write `src/main/resources/db/migration/V1__baseline.sql` so the first migrate has a
version to record (an empty script fails nothing, a missing directory does nothing — this one documents intent):

```sql
-- Baseline migration generated by iru-setup-quarkus-service. Add V2__... scripts for the first real tables.
SELECT 1;
```

(Liquibase: `src/main/resources/db/changeLog.xml` with an empty `<databaseChangeLog>` and
`quarkus.liquibase.change-log=db/changeLog.xml`.) Don't write a sample `@Entity`: the first real one comes from a
task, together with its migration, so the schema and the mapping never disagree.
